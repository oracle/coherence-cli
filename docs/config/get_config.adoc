== Get Config

include::../../build/_output/docs-gen/get_config.adoc[tag=text]

*Example*

[source,bash]
----
cohctl get config
----
Output:
[source,bash,subs="attributes"]
----
CONFIG
------
Version             :  {cli-version}
Current Context     :  fp1
Debug               :  true
Color               :  on
Request Timeout     :  30
Default Bytes Format:  m
Default Heap        :  512m
Use Gradle          :  false
----

NOTE: Use `cohctl get config -v` to display cluster connections and profiles, including each
saved connection's `Ignore Invalid Certs` value. Use `cohctl get ignore-certs -c NAME` to inspect
one saved connection. For HTTPS, `false` verifies certificates; `true` allows invalid certificates
only for that connection's HTTPS origin. HTTP and other connections report `n/a`.
See xref:../examples/tls_certificate_validation.adoc[TLS Certificate Validation Changes].
