== Coherence CLI Installation

The Coherence CLI is installable on a variety of platforms and architectures including macOS, Linux and Windows.
Refer to your operating system below:

*The latest version of the CLI is {cli-version}*.

* <<install-linux, Install on Linux>>
* <<install-macos, Install on macOS>>
* <<install-windows, Install on Windows>>
* <<uninstall, Removing the CLI>>

See https://github.com/oracle/coherence-cli/releases[here] for all supported platforms.

NOTE: If there is a platform you would like included, please submit an issue https://github.com/oracle/coherence-cli/issues/new/choose[here].

[#install-linux]
=== Linux

The Linux installer downloads the release checksum manifest and verifies the selected binary before making it executable or copying it to `/usr/local/bin`:

[source,bash,subs="attributes"]
----
curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/oracle/coherence-cli/main/scripts/install.sh | bash
----

NOTE: When you install the CLI, normally administrative privileges are required as the `cohctl` executable is moved to the `/usr/local/bin` directory.
If you do not want to copy to `/usr/local/bin` automatically, you can set the following environment variable `export COPY=false`, before running the above to download only and then
manually copy to your desired location.

As a first-class alternative to piping the installer into Bash, download and verify the artifact and manifest manually:

[source,bash,subs="attributes"]
----
(
set -euo pipefail
VERSION="{cli-version}"
while [[ "${VERSION}" == *$'\r' ]]; do VERSION=${VERSION%$'\r'}; done
[[ "${VERSION}" =~ ^[0-9A-Za-z][0-9A-Za-z._-]*$ ]] || { echo "Invalid version" >&2; exit 1; }
ARCH=amd64 # use arm64 on Arm systems
ASSET="cohctl-${VERSION}-linux-${ARCH}"
MANIFEST="cohctl-${VERSION}-checksums.txt"
RELEASE_URL="https://github.com/oracle/coherence-cli/releases/download/${VERSION}"
DESTINATION="${PWD}/${ASSET}"
TEMP=$(mktemp -d)
trap 'rm -rf -- "${TEMP}"' EXIT
cd "${TEMP}"

curl -fsSL --proto '=https' --proto-redir '=https' -o "${ASSET}" "${RELEASE_URL}/${ASSET}"
curl -fsSL --proto '=https' --proto-redir '=https' -o "${MANIFEST}" "${RELEASE_URL}/${MANIFEST}"
awk -v target="${ASSET}" '
    $2 == target {
        matches++
        if (NF == 2 && length($1) == 64 && $1 !~ /[^0-9a-f]/) {
            valid++
            entry = $1 "  " $2
        }
    }
    END {
        if (matches != 1 || valid != 1) exit 1
        print entry
    }
' "${MANIFEST}" > "${ASSET}.sha256"
sha256sum -c "${ASSET}.sha256"
chmod u+x "${ASSET}"
mv -- "${ASSET}" "${DESTINATION}"
)
----

[#install-windows]
=== Windows

Download the executable and checksum manifest, require exactly one matching manifest entry, and compare it with the locally calculated SHA-256 value:

[source,powershell,subs="attributes"]
----
& {
    $ErrorActionPreference = 'Stop'
    Set-StrictMode -Version Latest
    $Version = "{cli-version}"
    if ($Version -cnotmatch '\A[0-9A-Za-z][0-9A-Za-z._-]*\z') { throw 'Invalid version' }
    $Asset = "cohctl-$Version-windows-amd64.exe"
    $Manifest = "cohctl-$Version-checksums.txt"
    $ReleaseUrl = "https://github.com/oracle/coherence-cli/releases/download/$Version"
    $Temp = Join-Path ([IO.Path]::GetTempPath()) ([Guid]::NewGuid().ToString())
    $null = New-Item -ItemType Directory -Path $Temp
    try {
        $BinaryPath = Join-Path $Temp $Asset
        $ManifestPath = Join-Path $Temp $Manifest
        Invoke-WebRequest "$ReleaseUrl/$Asset" -OutFile $BinaryPath -ErrorAction Stop
        Invoke-WebRequest "$ReleaseUrl/$Manifest" -OutFile $ManifestPath -ErrorAction Stop
        $Entries = @(Get-Content -LiteralPath $ManifestPath -ErrorAction Stop | Where-Object {
            $Fields = $_ -split '\s+'
            $Fields.Count -ge 2 -and $Fields[1] -ceq $Asset
        })
        if ($Entries.Count -ne 1) { throw "Expected exactly one checksum entry for $Asset" }
        $Pattern = '\A([0-9a-f]{64})  ' + [regex]::Escape($Asset) + '\z'
        if ($Entries[0] -cnotmatch $Pattern) { throw "Malformed checksum entry for $Asset" }
        $Expected = $Matches[1]
        $Actual = (Get-FileHash -LiteralPath $BinaryPath -Algorithm SHA256 -ErrorAction Stop).Hash.ToLowerInvariant()
        if ($Actual -cne $Expected) { throw "Checksum verification failed for $Asset" }
        Copy-Item -LiteralPath $BinaryPath -Destination C:\path\on\your\PATH\cohctl.exe -ErrorAction Stop
    } finally {
        Remove-Item -LiteralPath $Temp -Recurse -Force -ErrorAction Stop
    }
}
----

NOTE: Change `amd64` to `arm64` for an Arm-based processor. You can also download the relevant files from https://github.com/oracle/coherence-cli/releases[GitHub Releases].

Release checksums detect corruption or mismatched content. Because the checksum manifest is published with the same release, it does not provide independent provenance if an attacker can replace both the artifact and manifest.

[#uninstall]
=== Removing the CLI

To uninstall `cohctl`, for Mac, issue the following:
[source,command]
----
sudo rm /usr/local/bin/cohctl
----

For all other platforms, remove the `cohctl` executable from where you copied it to.

If you also wish to uninstall the hidden configuration directory, `.cohctl`, where `cohctl` stores its configuration,
you will find this off the users home directory. See xref:../config/changing_config_locations.adoc[here] for more information.

For example on macOS or Linux the directory is `$HOME/.cohctl`, for Windows it will be under `%HOME%\.cohctl`.
